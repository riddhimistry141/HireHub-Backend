Controller
├── Read req.body / params
├── Validate request
├── Prepare data object
└── Call service

Service
├── Business rules
├── Authorization/ownership logic
├── Reusable database helpers
├── Password hashing / JWT generation
└── Prisma queries

Routes
└── Middleware + controller
